# AgentRelease 0.1.0 experimental release

Status: experimental GitHub prerelease, under development. Tag: `v0.1.0`.
Independent acceptance: pending. No production readiness is claimed.

## Scope

For developers and reviewers with existing test outcomes, AgentRelease checks
strict JSON evidence against mandatory tests and numeric thresholds in safe
YAML policies. It supplies a Python API and CLI, four evaluation states,
reproducible text and JSON reports, and explicit automation exit codes.
The included observations are synthetic, not a validated agent integration.

## Install

Python 3.12 or newer is required. Download and verify the release files, then
use [the clean installation guide](https://github.com/lynvera-ai/agentrelease/blob/v0.1.0/docs/external-review.md). Install PyYAML from
the pinned runtime requirements and the local wheel with `--no-deps`.
The source archive contains examples and documentation; the wheel contains the
library and CLI. Source cloning from GitHub remains available for the existing
tagged source. Download the files from the
[v0.1.0 release](https://github.com/lynvera-ai/agentrelease/releases/tag/v0.1.0).
This release is not published to PyPI.

## Included in this release

- Formal English documentation and a matching Spanish quick start.
- Original local SVG banner and factual static badges, with no remote graphics.
- Contribution, issue reporting, security and independent review instructions.
- Pinned dependencies and local reproducible build tooling, including checksums
  and build metadata tied to an exact source commit.
- Previous report files are protected. Reusing an output path now returns
  OUTPUT_IO, exit 3; use a new filename.
- Strict static type checking with pinned tools, explicit validation-boundary
  types and compatible parser signatures.
- A portable candidate checker that installs the wheel into a fresh environment
  and produces a sanitized review result while leaving independent acceptance pending.

Version 0.1.0 and alpha metadata are retained for the first GitHub prerelease.
It does not represent a stable or beta release.

## Validation

The baseline was 147 passing tests on 2026-10-28. That is historical evidence.
Local runtime tests passed with 149 tests in each environment listed below.
The release uses the same runtime source as that validated snapshot; only
release documentation changed. Build identity is recorded in
`BUILD-METADATA.json`, with package hashes in `SHA256SUMS`. These local results
are not independent acceptance. No external approval is claimed.

## Limitations and pending work

Local tests cover macOS Apple Silicon with Python 3.12.9, 3.13.6 and 3.14.4,
and Debian Linux ARM64 in a container with Python 3.12.16, including a non-root
run. Each environment passed 149 tests. Strict mypy analysis passes for package
and maintenance tools, targeting Python 3.12. Windows, Linux x86-64 and other
platform combinations remain pending; see the [matrix](https://github.com/lynvera-ai/agentrelease/blob/v0.1.0/docs/validation-matrix.md).
The wheel's platform tag does not establish testing on those pending systems.

No test collection, agent execution, framework integration, evidence
authentication, statistical inference, optional criteria, cloud service,
database, authentication service or paid API is included. Numeric comparisons
are exact Python comparisons with no tolerance or unit conversion.

Report writes are not transactional and can leave a partial new file if
interrupted. The local file limits and safe loader are not a claim of security
against every adversarial workload. API and schema stability remain experimental.

Before a stable version, gather independent installation evidence, validate
the intended platform matrix, address reported defects and define an API/schema
compatibility policy. Future releases, PyPI publication and any longer support
policy require separate decisions. Do not replace the published `v0.1.0` tag
or its artifacts.
