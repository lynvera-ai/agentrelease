# AgentRelease 0.1.0 candidate notes

Status: experimental, under development. Prepared locally; not published.
Independent acceptance: pending. No production readiness is claimed.

## Scope

For developers and reviewers with existing test outcomes, AgentRelease checks
strict JSON evidence against mandatory tests and numeric thresholds in safe
YAML policies. It supplies a Python API and CLI, four evaluation states,
reproducible text and JSON reports, and explicit automation exit codes.
The included observations are synthetic, not a validated agent integration.

## Install

Python 3.12 or newer is required. Receive and verify the candidate files, then
use [the clean installation guide](../external-review.md). Install PyYAML from
the pinned runtime requirements and the local wheel with `--no-deps`.
The source archive contains examples and documentation; the wheel contains the
library and CLI. Source cloning from GitHub remains available for the existing
MVP. The preparation branch and these artifacts have not been uploaded.

## Changes in this candidate

- Formal English documentation and a matching Spanish quick start.
- Original local SVG banner and factual static badges, with no remote graphics.
- Contribution, issue reporting, security and independent review instructions.
- Pinned dependencies and local reproducible build tooling, including checksums
  and build metadata tied to an exact source commit.
- Previous report files are protected. Reusing an output path now returns
  OUTPUT_IO, exit 3; use a new filename.

Version 0.1.0 and alpha metadata are retained. This prepares an unpublished
experimental version; it does not represent a new stable or beta release.

## Validation

The baseline was 147 passing tests on 2026-10-28. That is historical evidence.
Current local results and artifact identities are recorded after building in
the accompanying candidate validation file. They must not be represented as
independent acceptance. No hosted test badge or external approval is claimed.

## Limitations and pending work

Only the available macOS Apple Silicon and Python 3.12 environment is checked.
Linux, Windows and other Python versions are pending. The wheel's platform
tag and requirement of Python 3.12 or newer do not establish those results.
No separate static type checker is configured.

No test collection, agent execution, framework integration, evidence
authentication, statistical inference, optional criteria, cloud service,
database, authentication service or paid API is included. Numeric comparisons
are exact Python comparisons with no tolerance or unit conversion.

Report writes are not transactional and can leave a partial new file if
interrupted. The local file limits and safe loader are not a claim of security
against every adversarial workload. API and schema stability remain experimental.

Before a stable version, gather independent installation evidence, validate
the intended platform matrix, address reported defects and define an API/schema
compatibility policy. Publication, tags and any longer support policy require
separate decisions.
